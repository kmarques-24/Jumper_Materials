This repository contains the jumping model described in the paper titled: RESCUE Jumper: A Centimeter-Scale Rolling and Jumping Robot for Search and Rescue. The code develops each phase of the model discussed in Section III. Jumping Model and analyzes experimental data discussed in Section IV. Experiments. The code was originally developed in Google Colab.

The sections are:
1. Setup
2. Experimental data analysis
3. Phase 1: Contact point and orientation after tail release
4. Phase 2: Tail extension until litfoff
5. Phase 3: Ballistic trajectory
6. Complete model pipeline
